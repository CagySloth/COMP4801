# Documentation

This repo has two main tracks:

1) **Matrix track**: simulate read matrices (`.reads.npz`) → phase → evaluate TSV accuracy  
2) **Long-read track**: FASTA → FASTQ → BAM → VCF → phase → evaluate VCF phasing
