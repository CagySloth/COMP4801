## Abstract

Haplotype phasing is an important part of genomic analysis because it puts heterozygous variants on the chromosome they came from. Long-read sequencing technologies (e.g., Oxford Nanopore Technologies, ONT) yield reads that encompass numerous variants and can enhance phasing contiguity. But practical phasing performance depends on how well the upstream alignment and variant calling work, as well as on long-read characteristics like uneven coverage, repetitive regions, and structured error patterns. WhatsHap is a popular phasing tool for long reads. To fully understand how it works from start to finish in real-world situations, you need a controlled and repeatable benchmarking environment.

This project creates a benchmarking pipeline that can be used over and over again. It makes a synthetic diploid reference genome, phased ground-truth variants and haplotypes, simulates ONT-like reads with adjustable realism settings, aligns reads, calls variants, and phases using a vendored WhatsHap core. It also checks the outputs against the truth. The pipeline can handle both oracle and called variant sets, which lets you separate phaser-limited and caller-limited regimes. Unit tests and an end-to-end test run are used to make sure the implementation works. Then, the framework is used for ablations and parameter sweeps to find failure modes and figure out how to optimize WhatsHap for practical use and long-read phasing workflows.
